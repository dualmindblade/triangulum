## Rules for every mission

**Start.** Your worktree may start from an old commit: run `git merge main`
first. Create `game/out/`. Pass
`--bake C:/code/triangulum/game/assets/world/seed42`, or copy that folder; never
link it.

**Disk.** C: is nearly full. Before your first build, write
`game/.cargo/config.toml` in your worktree:

```toml
[build]
target-dir = "E:/triangulum-build/<mission id>"
```

It's excluded from git. The binary is then at
`E:/triangulum-build/<mission id>/release/triangulum.exe`; run it from your
worktree's `game/`, or use `cargo run --release`. Never build into `target/` on
C:. Keep evidence under 30 MB. If C: drops below 3 GB free, stop and tell the
lead.

**Stay in your lane.** Write only inside your worktree and your build folder.
Don't touch `game/saves/` or `game/replays/` in the main checkout. Kill only
processes you started. Other agents are running, so any timing is provisional;
label it so.

**Evidence.** No repro, no fix. Each fix ends with a test that fails before it
and passes after it, and you look at real frames (before and after, same pose).
Run `cargo test --release` and every `.play` script your change could affect,
at least `scripts/m1-done.play`. Say plainly what you didn't verify.

**Shell.** Run multi-step shell work from a script file. The command guard
refuses Bash commands that run the game or git through variables, loops or
pipes.

**Docs.** Update `game/README.md` for anything a player or agent needs. Don't
edit `STATUS.md`, `PLAN.md` or `DESIGN.md`; put proposed wording in your findings
and the lead will apply it.

**Saves and replays.** A change to LOD-0 terrain needs the generator version
bumped, and a change to simulation rules needs `sim_rules` bumped; both make
older saves or replays refuse to load. Bump only when the rule really changed,
and make sure the refusal message tells a player what to do. Never delete a
save.

**Deliver.** Commits on your own branch; don't merge to `main` or push. Write
`docs/missions/<mission id>-findings.md` with evidence in
`docs/missions/<mission id>-evidence/`. Commit no full-screen captures; game
frames only. End with: branch and commit, what you verified and how, what you
didn't, and anything Andrew has to decide.
